# DEPLOY

## Build Artifacts
Production bundle is generated by:

```bash
npm run build
```

Output directory: dist/

## Pre-Deploy Checklist
1. npm run lint
2. npm run test
3. npm run build
4. Verify service worker and manifest files in dist/

## Firebase Security
This repository includes baseline rules:

- firestore.rules
- storage.rules

Before production deploy:
- review role claims mapping in authentication backend
- run Firebase emulator checks
- deploy rules with least privilege

## PWA Checklist
- Manifest served at /manifest.webmanifest
- Service worker served at /sw.js
- Offline page available at /offline.html
- Icons available under /icons/

## Hosting Notes
For SPA routing, configure fallback to index.html while preserving static assets and sw.js cache headers.

Recommended cache policy:
- index.html: no-cache
- static hashed assets: long max-age immutable
- sw.js: no-cache to allow update checks
